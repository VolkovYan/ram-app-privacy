၁။ မိတ်ဆက်

ဤမူဝါဒသည် Calvary Church Bible အက်ပ်နှင့် ၎င်း၏ဝဘ်ဗားရှင်းတွင် ကိုယ်ရေးအချက်အလက်များကို မည်သို့ကိုင်တွယ်သည်ကို ရှင်းပြထားပါသည်။ လက်ရှိဗားရှင်းတွင် ကျမ်းစာဖတ်ရှုရန် လိုအပ်သော ကျမ်းစာဒေတာကို အက်ပ်အတွင်း ထည့်သွင်းထားပါသည်။

၂။ အက်ပ်က စုဆောင်းသော အချက်အလက်

လက်ရှိ Android အက်ပ်သည် ကိုယ်ရေးအချက်အလက် သို့မဟုတ် အရေးကြီးသော ကိုယ်ရေးအချက်အလက်များကို စုဆောင်းခြင်း၊ ဆာဗာသို့ ပို့ခြင်း၊ ရောင်းချခြင်း သို့မဟုတ် အခြားသူများနှင့် မျှဝေခြင်း မပြုပါ။ အကောင့်ဖွင့်ရန် မလိုအပ်ပါ။ ကြော်ငြာ၊ analytics၊ push notification ဝန်ဆောင်မှုများကိုလည်း လက်ရှိဗားရှင်းတွင် မသုံးပါ။

ရှာဖွေသည့်စာသား၊ bookmark နှင့် highlight များကို ဖတ်ရှုနေစဉ် အက်ပ်၏ လက်ရှိ memory ထဲတွင်သာ ထားရှိသည်။ ၎င်းတို့ကို developer ထံ မပို့ပါ။ အက်ပ်ပိတ်ခြင်း သို့မဟုတ် စာမျက်နှာပြန်ဖွင့်ခြင်းဖြင့် အဆိုပါ ယာယီအချက်အလက်များ ပျောက်သွားနိုင်သည်။

၃။ ခွင့်ပြုချက်များနှင့် ပြင်ပဝန်ဆောင်မှုများ

လက်ရှိ Android အက်ပ်သည် တည်နေရာ၊ အဆက်အသွယ်၊ ကင်မရာ၊ မိုက်ခရိုဖုန်း သို့မဟုတ် ဓာတ်ပုံများကို ဝင်ရောက်ခွင့် မတောင်းပါ။ ကိုယ်ရေးအချက်အလက် စုဆောင်းရန် ရည်ရွယ်ထားသော ပြင်ပ SDK သို့မဟုတ် ကြော်ငြာဝန်ဆောင်မှုကို မထည့်သွင်းထားပါ။

ဝဘ်ဗားရှင်းကို အသုံးပြုသည့်အခါ ဝဘ်ဆိုက် hosting ဝန်ဆောင်မှုပေးသူက ဝန်ဆောင်မှုလည်ပတ်စေရန် IP လိပ်စာ၊ browser အမျိုးအစားနှင့် တောင်းဆိုသည့်အချိန်ကဲ့သို့သော ပုံမှန် server log အချက်အလက်များကို ကိုင်တွယ်နိုင်ပါသည်။ ထိုမှတ်တမ်းများကို ၎င်း၏ သီးခြားမူဝါဒအရ စီမံနိုင်ပါသည်။

၄။ ထိန်းသိမ်းခြင်းနှင့် ဖျက်ပစ်ခြင်း

အက်ပ်က ကိုယ်ရေးအချက်အလက်များကို ဆာဗာတွင် သိမ်းဆည်းခြင်း မရှိပါ။ ရှာဖွေမှု၊ bookmark နှင့် highlight များသည် ယာယီဖြစ်ပြီး အက်ပ်ပိတ်သည့်အခါ သို့မဟုတ် ဝဘ်စာမျက်နှာ ပြန်ဖွင့်သည့်အခါ ဖျက်ရှင်းသွားနိုင်ပါသည်။ ဝဘ် hosting log များကို hosting ပေးသူ၏ ထိန်းသိမ်းမှုစည်းမျဉ်းများအတိုင်း ကိုင်တွယ်ပါသည်။

၅။ ကလေးများ၏ ကိုယ်ရေးအချက်အလက်

ဤအက်ပ်သည် မည်သူ့ထံမှမဆို ကိုယ်ရေးအချက်အလက် စုဆောင်းရန် မရည်ရွယ်ပါ။ ကလေးများထံမှလည်း ကိုယ်ရေးအချက်အလက်ကို သိလျက်နှင့် စုဆောင်းခြင်း မပြုပါ။

၆။ မူဝါဒပြောင်းလဲမှုများ

အက်ပ်၏ လုပ်ဆောင်ချက် သို့မဟုတ် အချက်အလက်ကိုင်တွယ်ပုံ ပြောင်းလဲပါက ဤမူဝါဒကို ပြင်ဆင်ပြီး ဤစာမျက်နှာတွင် နောက်ဆုံးပြင်ဆင်သည့်ရက်ကို ပြောင်းလဲဖော်ပြပါမည်။
