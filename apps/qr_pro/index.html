Privacy Policy — QR လက်ထောက်

App: QR လက်ထောက် · Package: com.ram.qrpro_app · နောက်ဆုံးပြင်ဆင်သည့်နေ့: ၂၀၂၆ အောက်တိုဘာ ၁၈

ဤမူဝါဒသည် QR လက်ထောက် app က အချက်အလက်များကို မည်သို့ရယူ၊ အသုံးပြု၊ မျှဝေ၊ သိမ်းဆည်းသည်ကို ရှင်းပြထားသည်။ App တွင် account မလိုအပ်ပါ။ App developer က scan history သို့မဟုတ် QR content များကို သိမ်းဆည်းသည့် server မရှိပါ။

ကင်မရာနှင့် သင်ရွေးချယ်သောပုံများ

သင်က ကင်မရာ Scan ကို စတင်သည့်အခါ app သည် QR code ဖတ်ရန် live camera frame များကို အသုံးပြုသည်။ Gallery မှ QR ပုံကိုရွေးသည့်အခါ Android system photo picker ဖြင့် သင်ရွေးချယ်ထားသောပုံကိုသာ ရယူသည်။ Google ML Kit Barcode Scanning ဖြင့် image processing နှင့် QR ဖတ်ခြင်းကို သင့်စက်ပေါ်တွင် ပြုလုပ်သည်။ Camera frame၊ ရွေးချယ်ထားသောပုံနှင့် ဖတ်ရရှိသည့် QR content ကို app developer သို့မဟုတ် Google server သို့ မပို့ပါ။ App က ဤပုံများ သို့မဟုတ် QR content ကို မသိမ်းဆည်းပါ။

Google ML Kit နည်းပညာဆိုင်ရာ metrics

Android တွင် QR scan စတင်အသုံးပြုသည့်အခါ Google ML Kit SDK သည် diagnostics နှင့် usage analytics အတွက် အောက်ပါနည်းပညာဆိုင်ရာ metrics များကို Google ထံ ပေးပို့နိုင်သည်။

  • Device အချက်အလက်၊ ဥပမာ ထုတ်လုပ်သူ၊ မော်ဒယ်၊ Android version/build နှင့် ရရှိနိုင်သော ML hardware accelerator များ။
  • App package name နှင့် app version။
  • Installation တစ်ခုချင်းအတွက် identifier (အသုံးပြုသူ သို့မဟုတ် device ကို သီးခြားသတ်မှတ်ရန် ရည်ရွယ်ထားခြင်းမဟုတ်)။
  • ML Kit feature စတင်ခြင်း၊ detection, resource release ကဲ့သို့ event type၊ feature version နှင့် error code များ။
  • Performance metrics၊ image format/resolution ကဲ့သို့ API configuration၊ input/output size များ။

Google က ဤ metrics များကို HTTPS ဖြင့် encrypt လုပ်၍ ပို့ဆောင်ပြီး diagnostics, usage analytics, SDK ထိန်းသိမ်းခြင်းနှင့် တိုးတက်စေခြင်းအတွက် အသုံးပြုကြောင်း ဖော်ပြထားသည်။ Google ၏ ML Kit SDK disclosure အရ ဤ metrics ကို third party များထံ ထပ်မံမပေးပို့ပါ။ QR image နှင့် QR ထဲရှိ raw content ကို metrics အဖြစ် မပို့ပါ။ အသေးစိတ်ကို ML Kit Terms & Privacy နှင့် ML Kit data disclosure တွင်ဖတ်နိုင်သည်။

QR text, clipboard နှင့် မျှဝေခြင်း

QR ဖန်တီးရန် သင်ထည့်သည့် text နှင့် Scan ဖတ်ရရှိသည့် text ကို app က သင့်စက်ပေါ်တွင်သာ ပြသ/အသုံးပြုသည်။ “စာသားကူးမယ်” ကိုနှိပ်လျှင် text ကို Android system clipboard သို့ ကူးပေးသည်။ Clipboard ထဲရှိစာသားကို အခြား app များက သင် paste လုပ်သည့်အခါ ရရှိနိုင်ပြီး၊ clipboard ထဲတွင် သင်အစားထိုး သို့မဟုတ် ရှင်းလင်းသည့်အထိ ကျန်နိုင်သည်။

“QR မျှဝေမယ်” ကိုနှိပ်လျှင် app သည် QR code ၏ PNG ပုံကို Android system share sheet သို့ ပေးပြီး သင်ရွေးချယ်သည့် app သို့ ပို့ပေးသည်။ လက်ခံသည့် app က အချက်အလက်ကို မည်သို့အသုံးပြု၊ မျှဝေ သို့မဟုတ် သိမ်းဆည်းသည်ကို ၎င်း၏ developer က သတ်မှတ်သည်။ ထို app ၏ privacy policy ကိုစစ်ဆေးပါ။

  • Google: ML Kit နည်းပညာဆိုင်ရာ metrics များကို Google ထံပေးပို့နိုင်သည်။ Google က ၎င်းကို SDK diagnostics နှင့် analytics အတွက် အသုံးပြုသည်။

  • Android system clipboard: သင်ကူးယူရန်ရွေးချယ်သည့် QR text ကို ရရှိသည်။

သိမ်းဆည်းခြင်း၊ ဖျက်ခြင်းနှင့် လုံခြုံရေး

App တွင် account မရှိသလို developer က QR content, camera/gallery images သို့မဟုတ် scan history ကို app server ပေါ်တွင် မသိမ်းဆည်းပါ။ ထို့ကြောင့် developer ဘက်မှ ဖျက်ပေးရမည့် app account သို့မဟုတ် scan record မရှိပါ။ Clipboard အချက်အလက်ကို Android clipboard မှ ရှင်းလင်းနိုင်သည်။ မျှဝေထားသောပုံကို လက်ခံသည့် app ထဲတွင် သင်သီးခြားဖျက်ရနိုင်သည်။ Google ML Kit metrics များကို Google က ကိုယ်ပိုင် privacy policy နှင့် retention practices အတိုင်း ကိုင်တွယ်သည်။
